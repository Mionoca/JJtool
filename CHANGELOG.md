# Changelog

## [0.1.0] - 2026-05-12

### Added
- Desktop pet with draggable transparent window
- Multi-mood character system (happy, normal, angry, sleepy, working)
- Chat bubble interaction system
- Clipboard history monitoring and storage
- Clipboard panel with search, favorites, delete
- System tray integration
- Global hotkey Ctrl+Shift+V
- Settings window
- SQLite local database
- 3-day auto-expiry for clipboard data
